主菜单选择> ------ 文件处理 ------
  1  文件名机构标准化  【重命名配置：简称/全称/代码；键/值】
  2  文件排序前缀管理（添加 / 清理）  【文件排序配置：是否启用/排序前缀/匹配关键词】
  3  工作簿内容命名前缀（添加 / 清理）  【重命名配置：内容重命名启用/内容重命名取值规则】
  4  Office 格式转换（Excel 工作簿 → XLSX；支持 .xlsx 规范另存，DOC/WPS/WPT → DOCX）  【全局配置：excel目的格式/word目的格式】
  5  按配置修改 Sheet 名  【重命名配置：原表名/新表名（默认 J:K）】
  6  机构提交完整性检查  【提交检查配置】
  7  修复 Excel COM 无法打开的工作簿（生成修复副本；原件不变）  【自动补全角括号表名引号/修正冻结窗格矛盾】
  0  返回
----------------------
子菜单选择> → 批量修改 Sheet 名
  1  选择文件（可多选）
  2  选择文件夹（仅当前层）
  3  选择文件夹（递归子目录）
  0  取消
选择方式> → 正在打开文件选择窗口：批量修改 Sheet 名
→ 可手动输入路径（分号分隔），或输入 0 取消：
文件路径> → 已选择文件 1 个：
  1. rename-no-capability.xlsx
[确认] 将直接修改所选源工作簿的工作表名称，并保留备份。
.xlsx 改名时同时更新公式和命名区域引用；.xls 请先在 Windows 通过 4-4 转为 .xlsx。
输入 y/yes/是 执行；其他输入取消，不生成计划文件> [已取消] 未执行改名，也未生成计划或输出文件。
