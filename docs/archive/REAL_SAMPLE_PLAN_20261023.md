## 需要用户提供的材料

提供本机目录路径即可：脱敏配置、真实目录树/工作簿、对应旧版正确输出或可重复运行步骤。脱敏需保留 sheet 名/顺序、表头与批注指令、公式结构、合并、样式、行列尺寸和业务规则能命中的文件名结构；替换机构名/金额时同步改配置和黄金输出。不要直接把未脱敏源目录加入 Git。

按功能分别建 case，记录脱敏批准、输入 SHA-256、源实现文件哈希、运行命令/退出码、环境和独立输出。可复用一套经过批准的目录树，但每项操作在各自临时副本运行，不能串行改同一副本导致下一项输入漂移。源项目只读，Python 只在旧版基线中执行，设置 PYTHONDONTWRITEBYTECODE=1，输出/日志仅进临时目录。

## 隔离执行与证据捕获

1. 在样本清单登记脱敏批准和输入文件集合哈希；只读检查原目录。配置使用完整临时副本，改目录字段只改副本，记录重定向字段及配置前后哈希。
2. 基线与 Rust 各用独立、初始字节一致的副本，运行源 PyCode 函数和相应 Rust CLI；记录完整调用链的 command、exit_code、wall time、进程树 peak RSS（可测时）及最终文件树。未测量不填零。
3. 数据比较采用已有 Rust reader/probe 的明确值/公式合同。Calamine 未提供的版式保留项用已有专项 probe 和必要的测试辅助独立读回；不假定 Calamine 是样式读取器。空值/日期/错误值先在功能合同中声明，不能全局把合法空字符串当作缺失格。
4. 文件操作的相对路径及内容 SHA-256 用于验证字节保留；跨引擎工作簿用值/类型/公式和对象投影比较，不用文件或逐格 SHA 判浮点相等。浮点相对容差不超过 1e-15，零与非零不靠未声明的绝对误差放行；金额等需十进制合同的字段先归一字符串。
5. 正常、失败/冲突、重复运行都捕获证据。基线和 Rust 动态时间戳/绝对根路径只按预先列出的归一规则处理，不忽略全部路径、顺序或日志。
6. 使用下面的 harness 比较捕获产物。它只读产物，不启动业务、修改样本或执行能力记录；拿到样本目录结构后再接相应隔离运行捕获适配器，当前不假造端到端执行结果。
7. 即使产物逐项比较为“保留”，功能状态仍为“未验证”，直到真实保留项、完整失败矩阵、资源预算和目标系统离线 deb 验收完成。PT-7-4 实际修改另待后续能力登记步骤，不自行构造 Passed JSON 解锁。

性能采集前先登记规模、绝对节省时间/加速比例/峰值内存预算；未知值写“待确认”，不可用通用 benchmark 值补上。更改默认路由时还须满足规则13 §9.2；本批不改任何默认。

## 产物对拍 harness

入口：`real_sample_harness.ps1`（PowerShell 7，开发机辅助工具，不随产品 deb 交付）。输入模板：`../tests/fixtures/real-sample-plan.json`（相对本文件所在目录；直接运行时使用下列 workspace 路径）。每个 feature 的 cases 当前为空，表示缺样本。

从 workspace 根运行：

```powershell
pwsh -File pytools-core/probe/real_sample_harness.ps1 `
  -Manifest pytools-core/tests/fixtures/real-sample-plan.json `
  -Report pytools-core/probe/reports/PT_real_sample_intake_<日期与轮次>.json
```

无样本/产物缺项退出 2；有值差异同样退出 2；所有提供产物比较一致退出 0，**仍不代表功能或平台验收**。报告禁止覆盖；每轮新文件名。harness 自身是待真实样本验证的测试辅助，不新增依赖，不自动生成 capability。

取得样本后在对应 cases 填 `case_id`、`baseline_artifact`、`rust_artifact`（路径相对 manifest）。两份 artifact 由独立运行捕获器产生，最低结构为：

```json
{
  "schema_version": 1,
  "feature_id": "PT-4-1",
  "case_id": "用户提供并批准的case-id",
  "origin": "real_sanitized",
  "approved_sanitized": false,
  "run": {"command": [], "exit_code": null, "isolated_copy": false},
  "inputs": [{"id":"相同源输入的稳定标识","sha256_before":"待采集","sha256_after":"待采集"}],
  "result": {"stats": {}, "filesystem_entries": [], "config_integrity": {}}
}
```

这是格式说明，不是有效证据；批准、成功运行和真实哈希缺任一项都会拒绝比较。`result` 的 required_result_fields 按功能清单固定；`filesystem_entries` 按预先约定的相对路径排序记录文件/目录及字节哈希，workbook_projection/preservation/patch_scope 使用对应专项既有合同，不能用空对象冒充已完成对象覆盖。harness 的通用形状检查不能鉴定样本真实性或完整保真，须人工复核捕获器及具体字段；尚无真实数据的这些内容保持未验证。

当前运行 `PT_real_sample_intake_20261023_r2.json` 只记录 13 项缺样本闸门，没有真实运行或 Passed 能力；初轮报告保留。下一步需要用户给出样本目录及基线材料；此前不进入生产能力登记、后续业务组或 Audit 主链。
