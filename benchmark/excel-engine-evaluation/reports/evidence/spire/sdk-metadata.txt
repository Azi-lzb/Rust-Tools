Rocky Linux 8.9 x86_64, glibc 2.28:
- libSpireXlsCpp.so and libSpireXlsBase.so direct ELF dependencies resolve.
- SDK umbrella header initially failed to compile because its byte typedef is conditionally omitted when __cpp_lib_byte is set; the smoke wrapper pre-includes <cstddef> and undefines the macro before including the vendor header.
- SDK core required explicit linking of both libSpireXlsCpp.so and libSpireXlsBase.so to resolve Workbook_CreateWorkbook.
- After compiling and bundling the SDK libraries plus Rocky 8 ICU, Workbook construction fails with TypeInitialization_Type_NoTypeAvailable while initializing worksheet types. Loader traces show runtime attempts to load libSkiaSharp.so.
- libSkiaSharp.so has direct dependencies on libfontconfig.so.1 and libm.so.6. `readelf --version-info` shows GLIBC_2.29, which is unavailable on the tested glibc 2.28 host. It also requires fontconfig/freetype stack components.
- Therefore the package cannot pass the required glibc 2.28 workbook load/modify/save smoke with the official 16.7.0 Linux SDK. Status: INCOMPATIBLE for the tested package/build path.
