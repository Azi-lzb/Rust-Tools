The Linux SDK includes libAspose.Cells.so (ELF64 x86-64), headers and CMake config. The official requirements list fontconfig as a Linux dependency. A custom C++17 read/modify/save smoke program compiled with Rocky Linux 8 GCC 8.5.0 but failed at link time against the vendor library:

- undefined reference to GLIBCXX_3.4.26
- undefined reference to log2/exp2/log/exp/pow@GLIBC_2.29
- undefined reference to FreeType palette symbols absent from Rocky 8's installed FreeType

The SDK library requests GLIBC 2.29 symbols, above the target glibc 2.28. No target libc was replaced. This test therefore stops at compile/link and is incompatible with the tested glibc 2.28 toolchain. C++ compiler/link output and ELF dependency files are retained beside this file.
