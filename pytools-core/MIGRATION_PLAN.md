# PyTools 业务范围与维护说明

本文件保留已确认的产品范围和排除项，不是全量迁移计划，也不定义新一轮任务或阶段门。当前开发方式见根 `AGENTS.md` 和 `DEVELOPMENT_GOAL.md`；现有菜单与状态见 `MIGRATION_INVENTORY.md`。

原 PyCode 及 NoComPyTools 是只读历史行为参考；NoCom 的独有差异保留为待用户确认的记录，不静默合并或生成第三个产品。Python 菜单、PyInstaller、虚拟环境和 Python 运行模式不是生产交付路径。

## 已确认业务范围

以下沿用旧功能编号记录业务范围；它们不是当前七类主菜单的编号，也不意味着每项都已通过人工验收或应立即补做：

- 时序：表头路径比对、两种宽表汇总、时序配置预校验。PT-1-2 时序提取已明确排除。
- 去重：按批注检查或删除；按配置检查、删除、追加到目标及配置预校验。当前主菜单呈现的范围与旧入口可能不同，已有实现和历史语义须保留。
- 打印：按批注保留格式、按批注快速复制、按配置准备静态打印工作簿和配置预校验。仅准备工作簿及其页面设置，不做 PDF 渲染或打印机输出。
- 文件处理和转换：批量重命名、工作表名称、按内容添加或取消前缀、局部名称映射、提交检查、排序前缀及撤销；同类转换保留 Excel `.et/.xls → .xlsx`、Word `.doc → .docx` 范围。可选引擎按操作和环境单独处理。
- 配置：初始化或修复配置表，查看并重新加载配置。
- 汇总：按使用区域汇总，按模板批注或命名区域汇总。
- 专用报表：拆分村镇银行数据、机构名称标准化、删除分机构表外资行、修改外汇页眉、地区总分校验、工作表数据提取、涉农贷款月度修正及季度修正/分地区核对。工作表提取仅包含普通无批注版。
- 归档：按日期或类型预览、执行归档计划、按日期或类型直接复制。
- 快捷操作：打开配置文件、打开 output 最新文件、打开 output 目录。

PDF 导出、跨类别转换、Python 模式切换及 COM 批注版提取已明确排除；已有相关代码不因此自动删除。原始输入、配置、公式和必要结构须保护，旧目标写入、去重追加及提取追加的差异化合同继续有效。

历史详细说明、旧阶段计划和对拍结果见 `../docs/archive/MIGRATION_PLAN_20261027.md`、`../docs/archive/MIGRATION_INVENTORY_20261027.md`，仅供查阅；其中旧分支、阶段要求与进度口径不再生效。
