## 修改目的

对齐 PyCode `run_summary_by_comment` 对空 `set()` 批注的解析行为。原 Python 正则 `set[\(（]([^)）]+)[)）]` 要求括号中至少一个字符；Rust 原解析把空捕获作为空名称，造成多余的空表头和输出列。

## 修改文件及内容

- `pytools-core/src/summary_ops.rs`：忽略零长度 `set()` 捕获；保留 Python 对 `set( )` 的行为（捕获非空，随后裁剪为空字符串）。
- `pytools-core/tests/summary_comments_cli.rs`：新增真实 `summary-comments` CLI 回归，用 Rust XLSX writer 生成带批注模板，校验不产生空集合列、行值和源文件不变。
- `pytools-core/probe/compare_summary_comments_empty_set.py`：新增针对该边界的 PyCode/Rust CLI 全投影对拍入口，支持 Ubuntu WSL debug 与 Windows 原生 Rust CLI。
- `pytools-core/probe/reports/summary_comments_empty_set_marker_parity_20261024.json`：保存合成对拍结果；仅含场景/计数/引擎，不含真实业务数据或凭据。
- `pytools-core/probe/reports/summary_used_range_windows_native_20261024.json`：保存 PT-6-1 Windows 原生对拍的汇总计数、引擎和状态；不含源文件名、路径或单元格内容。
- `pytools-core/MIGRATION_INVENTORY.md`：记录问题原因、修复和验收边界。
