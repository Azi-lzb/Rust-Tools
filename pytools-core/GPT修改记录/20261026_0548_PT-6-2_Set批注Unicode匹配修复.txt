目的：修复 PT-6-2 模板 set 批注名称解析与 PyCode `re.IGNORECASE` 不一致的问题。原 Rust 代码先对整段 Unicode 文本执行小写转换，再把转换后字符串的字节偏移用于原字符串；前置字符 `İ` 小写后扩展为多字节序列，使后续 marker 偏移错位，可能导致错误结果或 UTF-8 切片 panic。另补齐 Python 正则对长 s（`ſ`）的大小写匹配行为。

修改文件：
- `pytools-core/src/summary_ops.rs`：改为在原字符串的 UTF-8 字符边界上匹配 marker；只接受 Python `re.IGNORECASE` 对当前 ASCII marker 字母的等效大小写（含 `ſ` 对 `s`），并用安全字符串访问取名称，避免非法字节边界切片。新增两项单元回归。
- `pytools-core/tests/summary_comments_cli.rs`：新增实际 `summary-comments` CLI 集成回归，验证 Unicode 前缀后的 set 名称、结果数据和源/模板输入不变。
- `pytools-core/probe/compare_summary_comments_unicode_set_marker.py`：新增独立 Python/Rust 对拍脚本，覆盖 `İİset(区域)` 与 `ſet(区域)`。
- `pytools-core/probe/reports/summary_comments_unicode_set_marker_parity_20261026.json`：记录对拍范围和机器结果，不包含业务样本内容。
