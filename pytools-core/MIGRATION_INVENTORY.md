## 需要保留的限制

- Excel 编辑器：既有工作簿按操作、格式、对象、平台和对应 capability 选择后端。测试用临时 capability 不等于生产能力；超出已验证范围应安全拒绝。隔离 openpyxl worker 仅用于既有 XLSX 修改，非空公式缓存、未知部件等限制按现有实现处理。
- `ImportRange`：已有目标的去重追加、整表复制或追加依赖具体能力；历史上部分路径仅用合成临时 capability 验证。openpyxl 路径对行插删及 ImportRange 尺寸复制有限制。
- `SetComment`：历史配置修复合成操作批次中，umya 候选未保留预期表头批注；openpyxl worker 在合成及真实配置副本上有局部通过证据，但仅使用临时测试 capability，不能等同于生产验收。详见 `probe/reports/config_repair_execution_20261023.json`。
- 转换与计算：XLS/ET、DOC 及引擎能力各自记录，ET 原生正向样本仍缺证据。公式重算默认关闭，旧缓存不等于重新计算；Office、WPS、LibreOffice 等只能作为明确选择的可选能力。
- 结构与安全：原文件、业务数据、公式、合并及明确需要保留的结构必须保护；改表名、插删行和追加须考虑引用与目标冲突。普通字体、边框等外观差异不自动阻塞交付。
- Linux 目标仍为 x86_64、glibc 2.28 和离线 deb。历史特定二进制或样本的验证不等于当前版本、目标发行版及所有功能均已验收。
- 历史比较辅助：`probe/compare_real_rules_wide.py` 使用本项目相对路径，仅供按需比较，不属于默认验证流程。其辅助脚本未指定现有 EXE 时会调用 `cargo run`；任何 Rust 执行均须用户明确授权。其他比较辅助及 `probe/probe.toml` 仍可引用只读原 Python 项目。

## openpyxl 运行时与就地修改（2026-10-29 状态）

- openpyxl 子进程为 IPC（独立 Python 进程 + JSON 文件交换），非 FFI。
- 运行时解析已统一到 `OpenpyxlWorkerConfig::resolve_runtime`（预检与执行共用）：
  显式环境变量 → deb libexec 布局 → Windows ZIP `python/` 布局（兼容
  `python/runtime/bin/` 变体）→ 开发树（仅 debug 构建，或
  `PYTOOLS_OPENPYXL_DEV_TREE=1` 显式允许；解释器仍须 `PYTOOLS_OPENPYXL_PYTHON`
  显式提供）；PATH 系统 Python 不构成受支持分发，缺失时列出全部查找位置。
  显式覆盖两个变量必须同时设置且有效，否则返回明确配置错误。解析含 10 项
  布局/覆盖/错误信息单元测试（含中文、空格与 Unicode 路径）。
- worker `--version` 协议握手（`WORKER_PROTOCOL_VERSION = 1`，与 Rust
  `PROTOCOL_VERSION` 须同步）：版本不匹配/环境不完整在派发前报“能力不可用”，
  错误区分环境问题与协议问题；worker 还会报告 openpyxl 是否可用（缺失时
  退出码 3）。握手成功按「解释器路径 + worker 路径 + 双方文件版本标识」
  缓存，worker/运行时被替换后失效；探测本身有 30 秒超时与输出上限。
- 跨平台进程树清理：Windows 用 Job Object（CREATE_SUSPENDED 先入 Job 再恢复
  主线程，KILL_ON_JOB_CLOSE 兜底），Unix 用独立进程组（kill -pgid）。超时或
  异常时终止整棵受控进程树并回收直接子进程；测试验证孙进程不再存活。
  worker/响应日志各有 64 MiB 单次上限，超限终止进程树；响应 JSON 有大小
  上限与解析诊断；stderr 诊断按首尾保留 + TRUNCATED 标记有界读取；失败
  消息含类别、中文原因、修复建议与 run_id/协议/退出码/耗时诊断行。
- 上述改动已由自动化测试覆盖（excel-editor 11 个测试目标 79 项全部通过，
  Windows 与 WSL Linux 双平台执行；含修复后通过的端到端
  `rust_modifier_invokes_one_batch_worker_and_preserves_source`、
  Linux 进程组终止 + 孙进程不再存活断言的
  `timeout_terminates_tree_and_descendants`，以及"清理时发生错误"注入用例
